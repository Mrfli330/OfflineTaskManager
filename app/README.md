# Offline Task Manager

## Deskripsi
Offline Task Manager adalah aplikasi Android untuk membantu pengguna mengelola tugas kuliah secara lokal tanpa bergantung pada koneksi internet.

## Fitur
- Menambahkan tugas kuliah.
- Melihat daftar dan detail tugas.
- Mengedit informasi tugas, termasuk deadline.
- Mengubah status tugas menjadi Belum, Proses, atau Selesai.
- Menghapus tugas dengan konfirmasi.
- Menyimpan data secara lokal menggunakan Room Database.

## Teknologi
- Kotlin
- Android Studio
- Jetpack Compose
- Navigation Compose
- ViewModel
- Room Database

## Penyimpanan Data
Aplikasi menggunakan Room Database untuk menyimpan data tugas secara lokal pada perangkat.

## Cara Menjalankan
1. Clone atau unduh repository proyek.
2. Buka proyek menggunakan Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Jalankan aplikasi menggunakan emulator Android atau perangkat yang kompatibel.

## Pengujian
Fitur tambah, lihat, edit, hapus, perubahan status, dan penyimpanan data telah diuji pada aplikasi.
